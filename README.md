# WAVEROCK 지점별 세팅 이미지

세팅 달력(https://igoodimin.github.io/waverock-Routesetting-calendar/)의 일정을 읽어 지점별 세팅 안내 이미지를 만듭니다.

- 지점과 월을 고르면 그달에 **시작하는** 일정이 섹터 칸에 들어갑니다.
- 그달 일정이 없는 섹터는 다음달 첫 일정을 넣고, 그것도 없으면 이전달 마지막 일정을 넣습니다.
- `브라운1&2`, `해피 & 미드나잇`처럼 묶인 일정은 각 칸에 모두 들어갑니다.
- 미리보기의 글자를 클릭하면 고칠 수 있습니다. 고친 내용은 새로고침하면 사라집니다.
- 출력: 2160 × 2700 px, 150 dpi PNG

## 배경 이미지 바꾸기

`assets/` 폴더의 파일을 같은 이름으로 덮어쓰면 됩니다. 크기는 2160 × 2700을 권장합니다.

| 지점 | 파일 |
| --- | --- |
| 남천점 | `assets/bg-nam.jpg` |
| 서면점 | `assets/bg-seo.jpg` |
| 부산대점 | `assets/bg-bus.jpg` |

PNG로 바꾸면 `config.mjs`의 `bg` 경로도 함께 고칩니다.

`reference/`는 위치를 맞출 때 쓴 완성본입니다. 사이트 동작에는 필요 없습니다.

## 로컬 실행

```bash
python3 -m http.server 5178
```
